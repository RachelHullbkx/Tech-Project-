# Reflection
Before starting this project, I had very little knowledge of how to create a website and honestly felt quite intimidated by the technical side of web development. Because of that, I was genuinely surprised by how quickly Copilot generated the initial layout and structure for SportSwap. While my first general prompt gave me a solid foundation, I quickly realized that being specific with my follow-up prompts made a massive difference in refining the design and adding custom features. One of my favourite parts of the process was building the interactive network effects slider. By giving a detailed prompt asking Copilot to show how platform value grows as the user base scales from 100 to 1,000 community members, I saw how clear direction allows AI to translate a business concept into a functioning, visual tool.
Although AI made creating the website much easier, I still experienced several challenges throughout this project, especially when it came to navigating GitHub at first. The interface and version control workflow felt confusing, which led to a stressful moment when both of my documents suddenly disappeared. Fortunately, I was able to recover my lost work by digging into the Git history and using commands in the terminal. That scare taught me firsthand why consistently saving, committing, and syncing your work is so critical in any digital project. Ultimately, I realized that while AI is an incredible tool for generating code, it cannot manage the entire process on its own—it still requires human oversight, patience, and real problem-solving when things go wrong.
One of the biggest lessons I took away from this project was the difference between creating a website and creating a successful business. Seeing how fast Copilot built SportSwap made me realize how easily a competitor could use AI to create a similar website in a short amount of time. Because of this, simply having a clean, functional site is nowhere near enough to maintain a competitive advantage. Long-term success relies on things AI cannot generate overnight, such as building genuine customer loyalty, earning community trust, and forming strong partnerships with local sports organizations. While the website was a great starting point, turning SportSwap into a real, sustainable business would require significant offline effort, marketing, logistics, and relationship-building.
